# Kit Decisions

## Power Kits (decided 2026-09-27)
- **Keep only the Legacy style:** the tall-frame kits.
  - Blue: `kit_power2`–`9`
  - Gold: `kit_powerB1`–`B9`
  - The rounded-body kits (`kit_power10–14`, `kit_powerB10–15`, "Ultra Power Kit I–V") are **dropped**.
- **Use:** XP storage. A kit is levelled up to **200**, and its stored XP can be dumped onto an item.
- **Tiers:**
  - Blue = **Legendary**
  - Gold = **Mythical**
- **Source:** drops from a **Kit Box**.
- **Stored XP = kit level (1–200) × base × slot multiplier.** Each kit is levelled up to 200; the lit slots are a blanket multiplier on that. The base is decided later.
  - Example: a full gold kit (9 slots = 72×) at level 200 holds 200 × base × 72.
- **Slot multiplier (additive):**
  - Blue: **+4× per lit slot**
  - Gold: **+8× per lit slot**

- Open:
  - names
  - the base XP amount
  - whether a kit can be used partly, and on which tiers
  - Kit Box drop rates
