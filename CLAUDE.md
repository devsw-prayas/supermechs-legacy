# SuperMechs Legacy

Fan recreation of SuperMechs (Gato Games), built from extracted original game files. Gato is aware of and okay with fan copies.

## Vision
- Combine the **pre-transformation era** item roster (large variety, fixed stats) with **transformation-era** items (tiers, transforms, levels).
- Deliver a **long single-player campaign**, not a PvP-first remake.

## Workflow rules
Work in phases, in order. Don't skip ahead:
1. **Catalog** every extracted file (sprites, item data, audio, config, formats).
2. **Item lists**: normalize both eras into one item format.
3. **Game plan**: campaign structure, progression, balance, systems.
4. **Build**: code only starts after the plan is agreed.

- Ask before scaffolding projects, installing packages, or making destructive changes.
- Keep progress in `.claude/tracking/` (see below) up to date as phases move.

## Planned stack (not set up yet)
- Next.js (App Router, TypeScript), game rendering in the browser (Phaser or canvas)
- Neon Postgres + Prisma for saves
- Auth.js with **Google** and **Discord** login

## Layout
- `extracted/old/flash-2017-03-23/`: Legacy Flash client (last one before transformation)
- `extracted/transform/supermechs-7.628.4/`: final Reloaded APK, unzipped
- `extracted/data/`: community item packs (Legacy 936, Reloaded 214)
- `extracted/sprites/<era>/`: png, svg, svg_idle, png_idle, layers/, anchors.json
- `extracted/early-reloaded/`: 2.411 APK (first Reloaded build)
- `tools/ffdec/`: JPEXS 26.3.0 portable SWF decompiler. CLI: `java -jar tools/ffdec/ffdec-cli.jar -export <type> <outDir> <file.swf>`
- `.claude/tracking/`: roadmap.md (full plan), progress, decisions, catalog, item-format, item-decisions (item-by-item review)
- `Plans/`: decisions per slot (`Side Weapons`, `Top Weapons`, `Torsos`, `Legs`, `Drones`, `Modules`, `Charge Engines`, `Hooks`, `Kits`, `Zones`), each with a decisions note, sprites and an `_archive/`. Torso, leg and drone notes are generated by `tools/torso_notes.py`, `tools/leg_notes.py` and `tools/drone_notes.py`
- `chosen/`: exported roster for Obsidian (per family: sprites, info.json, info.md)
- `data/`: items_raw.json, items_selected.json (the roster), reports/ (duplicates, art quality), review_export/
