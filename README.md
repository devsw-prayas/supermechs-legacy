# SuperMechs Legacy

A fan recreation of SuperMechs (Gato Games), planned as a long single-player campaign. It combines the pre-transformation item roster with the transformation-era tiers, transforms and levels. Gato is aware of and okay with fan copies.

**This repository holds only our own work: planning notes, tooling, the roster data and the art we made or changed (recolours and redraws).** The original game files (APKs, SWFs, extracted sprites) are **not** included.

## Where things are
- `.claude/tracking/`: roadmap, progress log, decisions, catalog and item format. Start with `progress.md`.
- `Plans/`: the decisions per slot (side weapons, top weapons, torsos, legs, drones, modules, charge engines, hooks, kits, zones). The torso, leg and drone notes are generated by `tools/torso_notes.py`, `tools/leg_notes.py` and `tools/drone_notes.py`.
- `data/`: the roster (`items_selected.json`), the raw master list, slot overrides and reports.
- `tools/`: the scripts that build the roster, recolour art and generate the notes.

## Status
Phase 2 (item lists) is nine of twelve slots planned; shields, teleporters and boss parts are left. Phases 3 (game plan) and 4 (build) have not started. Code only starts once the plan is agreed.
